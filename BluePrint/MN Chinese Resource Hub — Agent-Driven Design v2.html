The Hub doesn't just point people to resources — AI agents actively contact organizations, track every call and email, follow up when orgs go silent, and escalate automatically. The user is guided. The org is held to account.

The Vision Shift — What Makes This Different

Old design vs. what we're actually building

❌

Old Approach: "Here's a phone number, good luck"

The system finds a resource and shows the user a phone number. The user has to make the call themselves. If the org doesn't answer, the system has no idea. There's no tracking, no follow-up, no accountability. The user is left alone to figure it out — exactly the same problem they started with.

✅

New Approach: Agents Work on the User's Behalf

When a user needs food, housing, or legal help, an Outreach Agent sends a direct email or request to the organization on their behalf — with a unique tracking token. A Response Monitor Agent watches for replies. If the org doesn't respond in time, a Follow-up Agent automatically sends a reminder. If they still don't respond, an Escalation Agent contacts the next-best option. Every contact is logged in the Audit DB with timestamps. The user is updated in real time. The org's reliability score is adjusted with every interaction.

The 11 Agents — What Each One Does

Two teams working in parallel: user-facing navigation + accountability enforcement

👥 Team 1 — User-Facing Navigation Agents (5)

🧭
Intent Router
intent_router.py

First to run on every message. Detects whether the user needs crisis intervention, a resource, a policy explanation, or a life checklist. Crisis → bypasses everything and returns safety info instantly.

keyword scan Gemini classify crisis override
🔍
Resource Finder
resource_agent.py

Queries the RAG vector database to find verified MN organizations. Ranks results by combining semantic relevance with each org's current reliability score from the Audit DB — so unreliable orgs rank lower.

RAG search score-weighted rank
⚖️
Policy Interpreter
eligibility_agent.py

Decodes complex MN DHS rules — food assistance, childcare subsidies, Public Charge — into plain, culturally appropriate Chinese or English. Uses Gemini 1.5 Flash with MN policy docs as context.

Gemini Flash MN DHS docs
🌐
Translation Bridge
translation_agent.py

Ensures every output is culturally nuanced, not word-for-word. Simple UI text → HuggingFace Helsinki-NLP (free, instant). Legal/policy terms → Gemini + Bilingual Glossary JSON (locks MNSure → 明州健康保险).

HuggingFace ZH↔EN glossary lock
🗺️
Life Navigator
navigation_agent.py

Generates custom multi-step checklists tailored to the person's situation — "First Week" for newcomers, "Senior Social" for elderly visitors, "Housing Emergency" for those facing eviction. Bilingual output.

Gemini Flash checklist generation

🔍 Team 2 — Outreach & Accountability Agents (6) · The NEW Team

📧
Outreach Agent
outreach_agent.py

The new core of the accountability system. After the Resource Finder selects an org, this agent sends an outreach email on the user's behalf — with a unique tracking token — and logs the contact in the Audit DB. Phase 2 adds call/SMS via Twilio.

SMTP email token generation audit log
⏱️
Response Monitor
response_monitor.py

Runs on a cron schedule (every hour). Scans the inbox for emails containing valid tracking tokens. When a token is found, marks the referral as RESPONDED and updates the org score. When SLA expires with no match, fires a breach event.

IMAP inbox scan cron job token matching
🔄
Follow-up Agent
followup_agent.py

Sends a second-attempt email to the org when the first contact goes unanswered past the halfway point of its SLA window. Frames it as a gentle reminder. Also sends the user a status update: "We're still trying to reach [org]."

reminder email user notification
🚨
Escalation Agent
escalation_agent.py

When an org fully fails its SLA, this agent immediately finds the next-best alternative from the Resource Finder, initiates a new outreach email to that org, and presents the user with an update: "The first org didn't respond — here's who we contacted next."

re-query RAG new outreach user alert
📊
Gap Analyst
gap_analyst.py

Weekly: scans search logs to find resource categories where no verified orgs exist OR all listed orgs are consistently failing. Auto-generates a Gap Report showing which community needs are completely unserved — the core document for advocacy.

log analysis gap report
📋
Accountability Reporter
report_agent.py

Monthly: auto-generates a PDF accountability report — org scorecards, SLA breach counts, response rates, outcome rates, service gaps. Designed to be sent to 211, MN DHS, funders, or state legislators as evidence-based advocacy.

PDF generation monthly auto-run

SLA Response Windows — What Triggers Escalation

Each organization type has a response deadline. Miss it → automatic consequences

🚨 Crisis Shelters

Domestic violence, immediate danger, hate incidents

⏱️ SLA: 2 hours
→ Miss = instant reroute to Tubman / Day One hotline

🍎 Food & Healthcare

Food shelves, clinics, mental health services

⏱️ SLA: 24 hours
→ Miss = reroute to next org, score downgraded

🏠 Housing & Legal

Emergency shelter, rental aid, immigration legal help

⏱️ SLA: 48 hours
→ Miss = follow-up email + reroute at breach

🏛️ Government Agencies

211, MN DHS, county services — the accountability targets

⏱️ SLA: 72 hours
→ Miss = logged for policy/legislative advocacy report
📊

After 90 days of 211 non-responses: You will have a documented, timestamped record showing that 211 consistently fails its 72-hour SLA. The Accountability Reporter auto-packages this as a PDF that you can submit to MN legislative offices — far more powerful than a phone call that was ignored.

Technology Choices — All Zero-Cost

Free tools that do enterprise-grade work

🖥️ UI & Hosting

Streamlit — web app framework. Streamlit Cloud — free hosting with secrets.toml for API keys. GitHub — source of truth + auto-deploy on push.

🧠 AI Models

HuggingFace Helsinki-NLP/opus-mt — free translation. Gemini 1.5 Flash — free tier, complex queries. FAISS — free local vector DB for RAG.

📧 Outreach & Tracking

Gmail SMTP — send outreach emails (free). IMAP — scan for replies with tracking tokens. Phase 3: Twilio free tier for SMS follow-up.

🗃️ Audit Database

SQLite — zero-setup, local, instant. Phase 2 migration: Supabase free tier for cloud + real-time dashboard updates.

📊 Reporting

Plotly / Altair — interactive audit charts. ReportLab — auto-generate monthly PDF accountability reports for advocacy.

🔒 Privacy

No PII stored. Users identified by SHA-256 hash only. Search terms hashed. GDPR-aligned design. Org contact emails stored only for outreach logging.
